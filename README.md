# SOA App - أبناء الفوضى

- `index.html` / `style.css` / `app.js` (React) / `tailwind-config.js`
- `firebase.js` : Firebase Auth + Firestore (البيانات والحسابات مشتركة بين الجميع)
- `firestore.rules` : قواعد الأمان (انسخها إلى Firebase Console > Firestore > Rules ثم Publish)
- `logo.jpeg` : الشعار

## تغيير الشعار
بدّل `logo.jpeg` بصورتك. الشعار يُقصّ تلقائياً على منطقة معيّنة من الصورة، فإن اختلفت الصورة عدّل الأرقام
`LOGO_CROP` في أعلى `app.js` (x, y, w, h بالبكسل، ثم iw, ih = أبعاد الصورة الكاملة).
أفضل نتيجة: صورة خلفيتها سوداء، لأن الشعار يذوب في خلفية الموقع.

## الإعداد (مرة واحدة)
1. Authentication > Sign-in method > Email/Password > Enable
2. Firestore Database > Create database
3. Firestore > Rules > الصق `firestore.rules` > Publish
4. Authentication > Settings > Authorized domains > أضف دومين Vercel

## الحركات (Motion)
- الدخول: خيط ضوء ← حلقات ← الشعار يظهر بتدرّج ← «SOA» حرفاً حرفاً ← الأبواب تنفتح. زر «تخطي» يتجاوزها.
- بعد الأبواب: الصفحات تدخل بتدرّج، الأرقام تعدّ تصاعدياً، شريط التنقل يتوهّج، الأزرار الذهبية تلمع، الصف المعدَّل يتلوّن بالذهب.
- كل الحركات تُوقَف تلقائياً لمن فعّل «تقليل الحركة» في جهازه (prefers-reduced-motion).
- ملف الحركات في آخر `style.css` (قسم «Premium motion»)، ومدّة السبلاش في `Splash` داخل `app.js` (المصفوفة `T`).

## الرئيس والرتب والصلاحيات (متناسقة)
- الرئيس يظهر تلقائياً في قائمة الأعضاء (رتبة «رئيس» ويتصدر القائمة)، ويتزامن اسمه ومعرّفه مع حسابه. لا يُطرد ولا يُحذف ولا تُغيَّر رتبته.
- القائمة مرتّبة: رئيس ← شيخ ← نائب ← مشرف ← عضو، وفيها فلتر «الإدارة».
- بطاقة العضو (للرئيس): زر «الرتبة والصلاحية» لتغيير الرتبة وإنشاء/تغيير/سحب حساب الدخول في خطوة واحدة، وزر «إزالة من الإدارة» يُرجعه «عضو» ويحذف حسابه.
- اختيار صلاحية يرفع الرتبة تلقائياً (نائب الصناديق/النشاط ← نائب، شيخ السرقات/القبول ← شيخ، مشرف ← مشرف).
- صفحة الحسابات: اختيار الشخص من الأعضاء بدل الكتابة، وإنشاء الحساب يضبط رتبته (أو يضيفه للقائمة إن لم يكن فيها).
- في الأنظمة القديمة يُضاف الرئيس تلقائياً عند أول دخول له.

## الدخول السينمائي (إعصار)
عاصفة وبرق ← الإعصار ينهار نحو الشعار ← وميض ← ظهور الشعار و«SOA» مع أشرطة سينما وحبيبات فيلم. الأوقات في `SPL` داخل `app.js`.

## الشعار والباب
- الشعار صورة شفافة `logo-emblem.webp` (بدون خلفية، تعمل على iPhone Safari). لتغييره استبدلها بنفس الاسم (PNG/WebP شفاف). إن لم توجد يُستخدم `logo.jpeg`.
- لا أشرطة سوداء: الدخول يملأ الشاشة كاملة، وفي النهاية ينشقّ الباب نصفين ويظهر التطبيق.

## الألوان (الثيم)
- اللون الأساسي الآن «بلاتيني/تيتانيوم» على أسود فاحم (بدل الذهبي). الألوان كلها متغيّرات في أول `style.css`.
- لإرجاع الذهبي: في `index.html` غيّر `<html lang="ar" dir="rtl">` إلى `<html lang="ar" dir="rtl" data-theme="gold">`.
- الشعار مقصوص بصورة شفافة نظيفة (`logo-emblem.webp`) بدون أي خلفية أو مربع.

## تحديثات الواجهة والقائمة
- ترتيب القائمة: رئيس ← نائب ← شيخ ← مشرف ← عضو، مع أزرار ترتيب «حسب الرتبة / الأكثر نشاطاً / الأقل نشاطاً».
- الصناديق: يمكن تسليم الصندوق الواحد لأكثر من شخص (اختيار عدّة مستلمين).
- السرقات: «تصفير اليوم» و«تصفير الأسبوع» (بخطوتين للتأكيد) وتُسجَّل في السجل.
- حسابات جديدة بلا مهمة: «نائب» و«شيخ» (قراءة فقط حالياً مثل «مشرف»، وتُضاف لهم المهام لاحقاً). قواعد Firestore لا تحتاج تعديلاً.
- الدخول: إعصار أكثر واقعية (دخان وغبار أرضي وحطام وخطوط رياح)، شعار على شكل رقعة صلبة بإضاءة وملمس، وباب معدني ثقيل ينفتح بحركة ثلاثية الأبعاد مع تدفّق ضوء.
- الموقع يمتد لآخر الشاشة (نفس اللون تحت شريط المتصفح).
